# X岛 PWA

X岛匿名版的 PWA 客户端。

## 功能

- 版块 / 时间线浏览
- 串列表与详情
- 只看 PO / 正序倒序切换
- 引用点击跳转与弹窗
- 收藏 / 历史（本地持久化）
- 深色 / 浅色 / 跟随系统主题
- 发贴 / 回复
- 图片模糊 / 隐藏模式
- 搜索
- 无限滚动
- 响应式布局

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物在 `dist/` 目录。

## 部署

推送到 `main` 分支会自动通过 GitHub Actions 构建并部署到 GitHub Pages。
